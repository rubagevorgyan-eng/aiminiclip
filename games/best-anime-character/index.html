$20 Best Anime Character

Anime · 2 players + a host · one screen

Set the table

Characters come up one at a time in a random order, from Weak Human all the way to God Level.

  • Each player starts with $20. The highest bid wins the character.
  • Once a player has 5 characters, they can't bid anymore.
  • Each player gets 3 skips to throw a character out before anyone bids on it.
  • The host gets 5 master skips that work any time, and can gift a character to either player for free.
  • The team with the most stars (★) wins.
